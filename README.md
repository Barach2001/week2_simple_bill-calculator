# Week 2 Assignment: Simple Bill Calculator

A simple interactive Python program that asks for the price of one item and the quantity, calculates the total cost, and prints a formatted summary using an f-string.

## How to run

1. Make sure Python 3 is installed.
2. Open a terminal in this repository folder.
3. Run:

```bash
python bill_calculator.py
```

## Example

```text
Enter the price of one item: 50
Enter the quantity you want: 3
3 items at 50.00 each = 150.00
```
